# YouTube Mini Player — PiP 사용 흐름 수정 v1.1

> 개발용 소스입니다. Chrome 웹 스토어 제출용 최종본이 아닙니다.

## 모드 차이

- **A / PiP**: 유튜브 영상 탭을 찾고 포커스합니다. **그 페이지 오른쪽 아래 `PiP 미니 플레이어` 버튼을 직접 누르면** 브라우저 기본 PiP 창이 열립니다.
- **B / 작은 창**: 유튜브 검색/홈페이지를 **일반 브라우저 팝업 창**으로 엽니다. 항상 위에 떠 있는 PiP가 아닙니다.

**A 모드를 선택하거나 검색 버튼을 누르는 것 자체는 PiP 실행이 아닙니다.** 브라우저의 PiP API는 유튜브 페이지에서 발생한 직접적인 사용자 동작이 필요합니다. 따라서 팝업에서 새 창을 열어 PiP인 것처럼 보이게 하는 대신, 이미 열려 있는 영상 탭으로 이동하는 버튼을 추가했습니다.

## 기존 프로젝트에 적용하기

1. 기존 프로젝트 폴더를 백업합니다.
2. 수정 파일 5개를 덮어쓰고 `src/services/pipTabService.ts` 1개를 새로 추가합니다. 정확한 파일 경로와 내용은 복붙 문서를 참고하세요.
3. 프로젝트 최상위( `package.json`이 있는 폴더)에서 실행합니다.

```bash
npm install
npm run dev
```

4. `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램 로드** → 프로젝트의 `build/chrome-mv3-dev`를 선택하거나, 이미 로드했다면 새로고침합니다.
5. 기존 유튜브 영상 탭도 새로고침합니다. (확장 프로그램을 새로 설치/재로드한 경우 기존 탭에 콘텐츠 스크립트가 자동 반영되지 않을 수 있습니다.)

## 사용법

### A. 실제 PiP

1. 크롬에서 `https://www.youtube.com/watch?v=...` 형태의 일반 영상을 엽니다.
2. 영상을 재생합니다.
3. 확장 프로그램 팝업에서 `A · PiP`를 선택합니다.
4. `▶ 재생 중인 영상 탭으로 이동` 클릭 → 열려 있는 유튜브 영상 탭으로 이동합니다. **새 창을 생성하지 않습니다.**
5. 유튜브 **영상 페이지 오른쪽 아래에 별도로 나타나는** `▣ PiP 미니 플레이어` 버튼 클릭 → 영상만 표시되는 브라우저 기본 PiP 창이 열립니다.

영상 탭이 없으면 사용자에게 메시지를 보여줍니다. 이 경우 팝업에서 `일반 탭에서 검색`을 눌러 유튜브 영상을 먼저 연 뒤 페이지 PiP 버튼을 누르세요. 이 검색 동작은 명시적으로 **일반 탭을 엽니다**.

### B. 별도 작은 유튜브 창

1. 확장 프로그램 팝업에서 `B · 작은 창`을 선택합니다.
2. `검색` 또는 `유튜브 열기` 클릭 → 별도의 브라우저 팝업 창이 열립니다.
3. 이미 프로젝트가 연 팝업 창이 있다면 해당 창을 재사용합니다.

## 주의/한계

- **브라우저 PiP 자체도 별도의 작은 화면 창처럼 보일 수 있습니다.** 그러나 PiP에는 일반 브라우저의 주소창이나 탭 UI가 없고 영상만 보입니다.
- PiP 실행은 유튜브 페이지 안의 **사용자 직접 클릭**으로 트리거됩니다. 확장 팝업에서의 메시지를 통한 PiP 자동 실행은 사용자 활성화 제약 때문에 보장할 수 없습니다.
- 영상 재생 준비가 되지 않았거나 브라우저/유튜브 정책으로 PiP가 금지된 영상은 실행에 실패할 수 있습니다.
- `Alt+Y`는 확장 팝업을 여는 단축키이지 즉시 PiP 전환 단축키가 아닙니다.
- `.git`, `node_modules`, 개인 문서는 어떤 배포 ZIP에도 포함하지 마세요.
