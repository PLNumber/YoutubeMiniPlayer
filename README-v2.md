# YouTube Mini Player v2 — 기능 테스트용

세 가지 모드를 지원합니다.

- **PiP**: 검색하거나 URL을 붙여 영상 페이지를 연 뒤, 영상을 재생하고 페이지의 **영상 PiP로 보기** 버튼 클릭. 실제 영상 PiP를 지원하지만 브라우저의 사용자 클릭 조건 때문에 검색 단계에서 자동으로 바로 PiP가 뜨지는 않습니다.
- **라디오**: 검색하거나 URL을 붙여 영상 재생 후, 페이지의 **라디오처럼 듣기** 버튼 클릭. 유튜브 탭은 그대로 열려 있고 다른 탭으로 전환되어 음악/음성이 계속 들립니다. 오디오를 추출하거나 백그라운드 비표시 플레이어를 생성하는 방식이 아닙니다.
- **작은 창**: 기존대로 별도의 유튜브 팝업 창을 열어 검색/재생.

영상 링크(https://youtu.be/..., https://www.youtube.com/watch?v=..., 쇼츠/라이브) 붙여넣기도 지원하므로, 검색 단계를 건너뛸 수 있습니다.

## 개발 환경 실행

```bash
npm install
npm run dev
```

Chrome `chrome://extensions`에서 개발자 모드 > 압축해제된 확장 프로그램 로드 > `build/chrome-mv3-dev` 지정. 기존 확장을 새로고침하고 유튜브 탭도 새로고침하세요.

## 제약

- 실제 PiP는 YouTube 영상 페이지의 버튼을 사용자가 직접 눌러야 합니다. (Chrome의 일시적 사용자 활성화 제약)
- 재생 중인 유튜브 탭을 닫으면 라디오 재생도 멈춥니다. 브라우저/유튜브 자동재생 및 절전 정책이 적용됩니다.
- YouTube API를 통해 오디오를 분리하거나 숨겨진 플레이어에서 재생하지 않습니다. 유튜브 정책을 우회하지 않습니다.
- Chrome 실제 동작은 별도 실기 테스트가 필요합니다.
